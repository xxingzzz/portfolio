The Map: Is There a Better Way to Save and Find My Files?

Concept Design / Desktop App

UX RESEARCH CONCEPT DESIGN TEAM PROJECT

Background

We All Have Files We Can't Find — Especially When We Need Them Most

As design students, we juggle countless courses, assignments, and projects — each producing a flood of files across different formats and tools. Over time, our computers become cluttered with folders we barely remember naming and documents we can't relocate. The frustration peaks right before a deadline: we know the file exists somewhere, but we can't find it and don't know how to search for it. Is there a smarter way to store and retrieve files — one that works with how we actually think?

context illustration

Insight

People Don't Need a Better Folder System — They Need a Proactive Assistant

I interviewed five classmates with varying document management abilities. Despite their different skill levels, they shared the same frustrations around naming, categorizing, and searching. Everyone expressed a desire for their computer to take on some responsibility — not just a "bookshelf," but a more proactive assistant that helps recall information intuitively.

Together, we ran an ideation session and converged on a direction: combining a visual digital map with AI assistance. We tested four concept directions with users — and the feedback pointed clearly toward one winner.

The Concept

The Map — An AI-Powered Visual File Assistant

The Map reimagines file management as an interactive, spatial experience. Instead of digging through nested folders or typing exact file names, users navigate a visual map where files are organized by context, association, and recency — the way our memory actually works.

auto-categorization with cards

Proactive organization

AI auto-categorizes your files into visual cards

When you save a file, AI automatically suggests categories and creates card entries on your map — no manual sorting needed.

  • Auto-prompted categorization
  • Visual card-based file entries
  • AI-generated tags and filters
interactive search on map

Intuitive retrieval

Search by exploring, not just typing

Instead of recalling exact file names, users navigate the map spatially. AI proactively suggests search paths and surfaces related files based on context.

  • AI-prompted search suggestions
  • Context-based file surfacing
  • Filter by media format, time, and topic

A living map that grows with your files

The digital map provides a bird's-eye view of all your documents, visually clustered by relationship. It evolves as you add files, making your entire archive feel navigable and alive.

  • Spatial overview of all files
  • Visual clustering by association
  • Interactive zoom and explore
